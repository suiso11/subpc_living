# 適応成長（Growth Points）

> **状態**: active / supporting
> **位置付け**: 成長ポイント計測・表示機能の設計文書
> **対象範囲**: GPの計測と集計、`data/growth/growth.db`、`GET /api/growth`、Web表示
> **作成日**: 2026-07-14
> **更新日**: 2026-08-27
> **日付根拠**: Git commit date

この機能は、会話のたびに実際に増えた「次回以降の応答に使える資産」を計測し、Web画面に表示する。
モデルの重みを毎ターン更新している、または知能がGP分だけ上昇した、という意味ではない。

## 何が増えるか

- 成功した会話1往復: 10 GP
- RAGへ検索可能な記憶として保存: 追加10 GP
- Discordの訓練用会話例: 5 GP
- 👍/👎フィードバック: 15 GP
- 明示的な修正候補: 35 GP
- 個人化事実: 25 GP

Web、Discord、常駐音声、テキストCLI、音声テキストモードは同じ
`data/growth/growth.db` を共有する。SQLite WALを使うため、複数サービスから同時に追記できる。
成長台帳には会話本文を保存せず、文字数、経路、RAG保存成否などのメタデータだけを保持する。

Webの合計GPには、計測開始以前から存在する適応資産も次の重みで加算する。

| 適応資産 | 1件あたりGP |
|---|---:|
| RAG会話記憶 | 2 |
| RAG知識 | 5 |
| Discord訓練例 | 1 |
| フィードバック | 8 |
| 修正候補 | 25 |
| 個人化事実 | 10 |
| 会話要約 | 5 |

レベルNの開始点は `100 × (N - 1)²`。Web画面では合計GP、レベル、次レベルまでの進捗、
今日のGP、会話連続日数、記憶数、修正候補数、14日間の推移を表示する。応答が完了するたびに再取得し、
増分をアニメーション表示する。

## API

`GET /api/growth?days=14` はイベント由来GP、既存資産由来GP、内訳、日別推移を返す。
`days` は1〜90日に制限される。計測DBが利用できない場合は503を返すが、会話処理は継続する。
