# VRM モデル配置ディレクトリ (Phase 6b)

ここに `.vrm` ファイルを置くと、デスクトップのオーバーレイShell (Phase 6b の
VRMレンダラ) が自動で発見して読み込みます。

## 使い方

1. 所有権・ライセンスを確認した VRM 1.0 モデルをこのディレクトリへコピー
2. （任意）複数ある場合は環境変数で明示指定:
   ```bash
   set DESKTOP_VRM_MODEL=C:\path\to\your-model.vrm
   ```
3. 複数置いた場合は名前順で先頭のものが既定候補になる（6b 実装時に選択UI予定）

## ルール

- **第三者モデルを製品へ同梱しない**: このディレクトリはgitignore済み。
  取得したモデルの利用規約に従ってください
- ファイルは `glTF` マジックを持つ VRM 形式であること（ローダー側で検証）
- リポジトリにモデルをコミットしないこと

発見・解決ロジック: `src/desktop/avatar.py`
